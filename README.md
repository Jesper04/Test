# Portfolio AI Dashboard

A React + Vite prototype for a UK retail investor dashboard.

## Features

- Left-side navigation and clean dashboard layout
- Upload broker CSV exports with automatic parsing
- Portfolio performance metrics: CAGR, TWR, IRR
- Live holdings summary with market data placeholders
- Benchmark comparison against S&P 500 and FTSE 100
- Parsed transaction preview from messy CSV exports

## Run locally

```bash
cd /Applications/GitHub/Test
npm install
npm run dev
```
